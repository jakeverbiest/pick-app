# Long-walk test card — first walk on the vector basemap

For the walk on **2026-09-09**. Update group `854196d1`, commit `c6e0d30`.
All four maps now run on MapLibre GL + CARTO's vector style; Leaflet is gone from the app.

**Before you start:** force-quit PICK, reopen, wait ~10s, force-quit and reopen again. Check
Settings — the build stamp must have changed, or you are testing the old bundle and none of this
means anything.

---

## The five-minute gate — do these before committing to a long walk

If any of these fail, stop and say so; there is no point walking an hour on a broken map.

- [ ] **1. The map draws at all.** Open the Map tab. Streets, labels, and your past coverage
      colours appear. Give it 2-3 seconds — vector is slower to first paint than raster was.
- [ ] **2. Your past walks are there.** The green/yellow/red street shading from previous walks
      should be visible, not a blank map. *This is the one I most expect to fail* — it is the
      exact data that was being silently dropped before the pre-load fix.
- [ ] **3. Start a walk and watch the route draw.** The thick green corridor should follow you
      and the dot should stay under you.
- [ ] **4. Pinch, pan, zoom.** Gestures should feel normal. Zoom should be smooth and continuous
      now rather than stepping between levels.

## During the walk — the things I could not test

- [ ] **5. Does it survive the distance?** This is the real question. Watch for the map going
      blank, the app getting hot, or battery dropping faster than usual. **Vector rendering uses
      WebGL, which has a different memory and power profile from image tiles**, and this file's
      own history warns that long walks were a memory killer once before.
      → *If the map goes blank mid-walk, that is the failure. Note roughly how many minutes in.*
- [ ] **6. Lock the screen for a few minutes, then come back.** The route should still be
      drawing and the map should still be alive.
- [ ] **7. Streets turn green as you cover them.** Live recolouring still works.
- [ ] **8. Pickups appear as red dots** where the detector fires.

## Neighborhood / level mode

- [ ] **9. Tap into your neighborhood.** The rest of the city should dim to a soft cream veil
      with your hood cut out of it, and the map should frame the neighborhood.
- [ ] **10. Tap a street inside level mode.** A dark popup with "Cleaned N days ago" and an
      "Adopt this block" link. **Thin streets should still be easy to hit** — the fat invisible
      tap target was rebuilt differently, so this is worth a few taps.
- [ ] **11. Back out of level mode.** The veil clears and your overview coverage comes back
      rather than leaving a blank map.

## After the walk

- [ ] **12. Save the walk.** Normal save flow, count correction prompt appears.
- [ ] **13. Share the recap card — LOOK AT THE EXPORTED IMAGE, not the screen.**
      This is the one still-unverified risk from earlier today. The small map inside the shared
      image must not be blank. It can look perfect in the app and still export empty, because
      `react-native-view-shot` captures a WebGL canvas differently from image tiles.
      → *If the map is blank in the shared image, that is a real bug and reverting one file
      (`src/pick/ImpactMap.tsx`) fixes it without touching anything else.*

## What "broken" looks like, and what to do

| symptom | likely cause | action |
|---|---|---|
| Map blank on open | style or key failure | screenshot, tell Claude, roll back |
| Past coverage missing but map fine | pre-load race not fully fixed | note which layers are missing |
| Map dies mid-walk | WebGL memory | note the minute mark — this is the headline risk |
| Blank map in a *shared* image only | view-shot + WebGL | revert `ImpactMap.tsx` only |
| Taps on streets do nothing | hit layer ordering | note whether it fails everywhere or only in level mode |

**Rolling back is one command** and takes effect on the next app launch, so nothing here is
one-way. Do not push through a broken walk to "get the data" — a walk logged on a broken map is
worth less than the fifteen minutes it takes to roll back.
