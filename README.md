## Project Overview

PICK is an environmental wellness app where neighborhood cleanup is the practice. Users go on daily "pick walks" to de-stress, build streaks, and see their neighborhood get cleaner in real-time via a shared community map.

### Core Differentiator
- **Neighborhood status map** (shows "when was this cleaned?") — Litterati doesn't have this
- **Heat map of cleanliness** (red/yellow/green zones)
- **Wellness positioning** (streaks, habits, meditation)
- **Real-time zone tracking** (last cleaned timestamp)
- **Corporate wellness market** (B2B) — Litterati is single-market
