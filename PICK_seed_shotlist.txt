PHASE A -- ESTABLISHING  (grab before anyone else is out)

01  EMPTY STREET
    Frame: WS          Movement: Static, braced        Zoom: 0.5x       Len: 4s
    Focus: full street, deep focus
    Note:  Cold-open or B-roll filler. Morning light, before foot traffic.

02  HEADING OUT
    Frame: MS          Movement: Handheld, track backward   Zoom: 1x    Len: 5s
    Focus: both faces
    Note:  Front door / stoop to sidewalk -- the literal start of the ritual.


--------------------------------------------------------------------------------
PHASE B -- THE WORK  (the core cleanup pass)
--------------------------------------------------------------------------------

03  BLOCK WALK  ****REQUIRED****
    Frame: WS/MS       Movement: Handheld, side-track       Zoom: 1x    Len: 8s
    Focus: both, soft background
    Note:  Get 2-3 takes. This is the workhorse b-roll for every cut.

04  SPOTTING LITTER
    Frame: MS          Movement: Static / slow push-in      Zoom: 1x    Len: 3s
    Focus: face -> object
    Note:  He looks down, sees it, reacts. Let it be real, not cued.

05  HAND PICKUP
    Frame: CU          Movement: Static, low angle       Zoom: 1-2x     Len: 3s
    Focus: hand + item
    Note:  Crouch to bucket height. Portrait/shallow-focus mode if it holds
           steady.

06  INTO THE BUCKET
    Frame: ECU         Movement: Static                     Zoom: 2x    Len: 1.5s
    Focus: item / bucket rim
    Note:  Quick, satisfying insert -- the "drop" sound sells it as much as
           the frame.

07  GRABBER TOOL
    Frame: MS/OTS      Movement: Static / slight pan         Zoom: 1x   Len: 4s
    Focus: tool + litter
    Note:  Over-the-shoulder, following the grabber's reach.

08  BLOCK PROGRESS
    Frame: WS          Movement: Slow pan               Zoom: 0.5-1x    Len: 5s
    Focus: deep, both figures small
    Note:  Pull back to show scale -- two people, one block. Good act-break
           beat.


--------------------------------------------------------------------------------
PHASE C -- THE WORM MOMENT  (opportunistic -- don't force it)
--------------------------------------------------------------------------------

09  CURIOUS CROUCH
    Frame: CU          Movement: Static                     Zoom: 1x    Len: 2.5s
    Focus: face
    Note:  He's noticed something. Get the "what is that" expression first.

10  THE WORM
    Frame: ECU         Movement: Static, near-macro          Zoom: 2x   Len: 1.5s
    Focus: the worm, everything else soft
    Note:  Fast -- worms don't hold a mark. Phone low, brace on your knee.

11  REACTION SHOT
    Frame: MS/CU        Movement: Static / quick whip        Zoom: 1x   Len: 2s
    Focus: face
    Note:  Yours or his -- whoever reacts genuinely. Don't perform it twice.


--------------------------------------------------------------------------------
PHASE D -- APP DEMO  (separate 5-min pass, screen only, current navy build)
--------------------------------------------------------------------------------

12  TAP START  ****REQUIRED****

    Note:  Screen fills frame. This is Board A's panel 1.

13  WALKING POV
    Frame: MS/POV        Movement: Handheld, walking         Zoom: 1x   Len: 5s

    Note:  Phone held out at walking height, screen legible.

14  COUNTER TICK
    Frame: ECU           Movement: Static                    Zoom: 1x   Len: 1.5s

15  CONFIRM SHEET  ****REQUIRED****

16  MAP FILL-IN
